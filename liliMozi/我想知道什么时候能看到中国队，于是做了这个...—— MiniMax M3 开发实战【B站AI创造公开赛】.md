为了看球赛搞的，反正都日过这荡漾的灵魂。那个，请问一下，天台为什么关了呀？最近世界杯啊，我只是去晾一下被子，能麻烦帮我开一下吗？

你说的对，但是今天下雨。这届世界杯真是又精彩又让物业奶奶不安生。作为一个资深伪球迷，我最近每天都在困扰，怎么给我那不懂球赛的朋友解释什么叫“出线”，为什么这个金发男人身后总是挂着一个人？为什么美加墨世界杯不叫美墨世界杯？

刚好我立项那会儿，MiniMax M3发布了，于是我决定拿它试试手。我打算用 Web Coding 的方式做一个好玩又实用的世界杯工具箱。

首先映入我们眼帘的是“国足世界杯预测器”，它把亚洲区名额、国足当前排名、最近几届世预赛成绩等等揉成一个“入围希望指数”。只要输入出生年份，它就会告诉你，按现在这个趋势，大概在你多少岁可以在世界杯看到国足。嗯，至少在那个时候，我还熬得动。连一刻都没有为国足哀悼，接下来赶到战场的是“世界杯翻译官”。你身边一定有这样的人，对象、室友、爸妈也想感受世界杯热闹的氛围，但他们看不懂。这个功能，就是用对方听得懂的方式来安利世界杯。选一个他熟悉的东西，工具箱会自动生成一套类比卡，比如《原神》或者《甄嬛传》。下次有人不愿意陪你看球的时候，就拿这个给她，贼好用。

其他几个频道是为不同类型的球迷准备的。“出线计算器”就更实用了，它会根据实时赛果重算积分，顺手标出谁还活着。“球迷速成卡”能让你五分钟了解一个队伍。这届世界杯首次扩军到48队，这个功能就变得尤其好用。

话又说回来，我觉得做这个工具的过程还蛮有意思的。虽然 Web Coding 的经验充足，但这次我把 M3 接上小花之后，没先告诉她我想做什么样的工具箱，而是先问她：如果你要做一个世界杯工具箱，你会想要做成什么样子？M3 还挺有灵性的，它想把整个工具箱做成世界杯电视台。这些台标、频道号、跑马灯、闪烁的 LIVE 灯都是 AI 自己的主意，我没干预它的创作。然后我在后面贴了个像素风格的球场背景，那味儿就更浓了。它又把工具箱拆成不同电视频道，而且把每个频道当成独立产品在设计，好像它就是一个球迷，用类比的方式向人安利世界杯，像个成熟的产品经理。我有点饿了。整个过程就像我跟它说了句“我今晚想吃点好的”，它买了疯狂星期四，还顺带问要不要开瓶啤酒。它可能不是这个世界上最厉害的编程模型，但它很懂此刻的氛围。

而且我还做了一个能在我的小花 Agent 上运行的插件版本，直接接入大语言模型，还能让翻译器自定义领域。我把这个插件和 HTML 页面都开源了，想要玩的话随意使用。

我有一个姑父，他这辈子除了工作之外，用电脑最多的时间可能就是年轻时去黑网吧。但最近接触 Web Coding 后，他天天给我分享他做的小玩具。因为他老是把 AI 当成许愿机，只会把自己的最终目标告诉 AI，然后再让 AI 引导自己去写出那个过程。所以这次我以他的经历为灵感，把大多数设计的决策权都交给了小花和 MiniMax M3。虽说它并不是一个参数量比较大的模型，但还挺有风味的。我觉得 Web Coding 最有意思的点就在于抽卡是真的上头。
