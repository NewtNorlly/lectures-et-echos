当你不小心输错了自己的手机密码，如果没有任何提示，可能会感到困惑。这时加上动效的反馈，就可以起到用户引导的作用，加强用户对当前状态的感知度。UI中的动效设计不仅仅是让界面动起来，更是一种让交互操作变得更清晰、更容易理解的桥梁，已经成为了用户体验中不可或缺的一部分。那么常见的UI动效主要有哪些呢？

1、缓动。当界面中的元素突然运动时，会比较突兀、呆板，而采用缓慢加速或缓慢减速的方式，能够增强视觉感官的自然感，会更灵动。

2、视差。当页面中有多个元素时，元素之间不同快慢的运动速度会产生视差，能够构建丰富的层次感。

3、偏移和延迟。如果多个内容同时进行移动，这没什么问题，但缺少了些许变化，可以让它们之间的运动有一定的交错间隔，视觉上依然相关，同时能够增强活力。

4、遮罩。可以改变某个元素的显示区域，通过视觉上的引导无缝过渡到另一个页面，使得页面之间的关联性得到强化，能够提高用户的掌控感。

5、数值变化。在UI设计中，数值变化动效非常常见。动态化的呈现能够增强用户对于数据的感知和理解，很直观。

6、父子级。顾名思义就是当某个元素的属性发生改变时，所链接的其他元素也会同时发生属性变化，形成了元素之间的协同互动。

7、叠加。通过堆叠叠加可以拉开前景和背景的区分度，能够增强扁平化空间的层次结构，一般用于展示暂时隐藏起来的内容。

8、形态转换。通常是一个UI元素的样式无缝过渡到另一个状态所发生的形态的转换，能够保持视觉上的连贯性。

9、滑动和缩放。当元素在视图中进行可视化的移动或缩放，能够体现内容元素在空间上的关系。

10、克隆。一个UI元素分裂成其他元素，可以以一种动态连贯的方式描述内容之间的关联性。

11、维度。有时候可以不只是二维平面，赋予它空间的深度，可以让你的动效设计更有趣味性。
